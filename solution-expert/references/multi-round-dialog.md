## §1 多轮对话

| 用户追问 | skill 行为 |
|---------|-----------|
| "再细化 §X" | 重新展开该章节，保持其他章节不变 |
| "回滚具体怎么操作" | 展开 §5 回滚步骤为可执行 checklist |
| "给我 Feature Flag 命名" | 输出开关名、归属、默认值 |
| "如果 NFR 不达标呢" | 在 §4 风险添加新条目 + §5 回滚策略更新 |
| "还有别的方案吗" | 重新走 Step 3，新增备选 C / D |

多轮中**不要**重新调研或重新问 Step 2（除非用户主动要求），保留上下文。

---

## §2 何时停止提问

- 信息足够（无歧义）→ 停止提问，直接设计
- 还剩 1-2 个高价值问题 → 用 AskUserQuestion 一次性问
- 超过 3 个关键决策未澄清 → 拆任务或先做最小调研再问
- 用户已表态"你来决定"→ 给出默认选择 + 理由，不要追问
